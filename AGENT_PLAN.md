2. Внедрить использование инструментов (Tools) для чтения/записи файлов и выполнения команд.
3. Использовать файловую систему (`TODO.md`, `AGENT_PLAN.md`) для хранения контекста задач.
4. Подготовить инфраструктуру для RAG (pgvector) для долгосрочной памяти.
5. Очистить кодовую базу от неиспользуемых и пустых функций.
6. **Синергия с GitHub Copilot:** Настроить проект так, чтобы Copilot в редакторе и автономные Python-агенты использовали одни и те же правила и контекст.
