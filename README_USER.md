# Как хранится пользовательская информация

Источник истины по структуре и хранению (включая артефакты бэктестов/ботов): [README_DATA_STORAGE_STRATEGIES.md](README_DATA_STORAGE_STRATEGIES.md).

- **Postgres**: основные данные (стратегии/модули, модели, сонастройки, версии конфигов, реестр ботов)
- **Redis**: очереди задач, pub/sub
- **Файлы (артефакты)**: финальный bot config.json, результаты бэктестов и др.; исходники стратегий — в git, могут кэшироваться на диск

## Пример

- Пользователь создаёт стратегию — запись в БД (таблица `strategy_templates`)
- Запускает autotune — новая версия config_file
- Генерирует бота — config.json на диск, запись в bots
